رفع جزداني على GitHub Pages
1) سجل بحساب على github.com وفعّل التحقق بخطوتين (2FA).
2) New repository: الاسم jazdani، من نوع Public، ثم Create.
3) اضغط "uploading an existing file" وارفع كل ملفات هذا المجلد (index.html و manifest.webmanifest و sw.js و الأيقونتين).
4) Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save.
5) بعد دقيقة بيصير الرابط: https://اسمك.github.io/jazdani/
لتحديث التطبيق لاحقا: ارفع index.html الجديد فوق القديم بنفس الطريقة (Add file > Upload files).
